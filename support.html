よくある質問

再生できない場合
アプリ内で再生するには、Apple Musicへのアクセス許可とApple Musicの有効な利用環境が必要です。利用できない場合は、Apple Musicで曲を開いて確認できます。

位置情報が使えない場合
iPhoneの「設定」アプリで、GeoBeatの位置情報アクセスが許可されているか確認してください。自宅など別の場所で試したい場合は、アプリ内の場所シミュレート機能を利用できます。

選曲が場所と合わない場合
GeoBeatは、町名、市区町村名、都道府県名などの地域情報をもとにApple Musicのカタログを検索します。気に入らない曲が流れた場合は、次の候補を再生できます。

お問い合わせ

不具合や要望は、GitHub Issues からお知らせください。

FAQ

If playback does not work
In-app playback requires Apple Music permission and an active Apple Music playback environment. If playback is not available, you can open the song in Apple Music.

If location does not work
Open the iPhone Settings app and make sure location access is allowed for GeoBeat. You can also use the location simulation feature to try music for another place.

If the recommendation does not match the place
GeoBeat searches the Apple Music catalog using area information such as neighborhood, city, and prefecture. If you do not like the current song, play the next candidate.
